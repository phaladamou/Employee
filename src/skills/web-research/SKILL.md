# Web Research Skill

## When to use
- User needs information from the web
- Mission requires gathering data
- Question requires evidence-based answer

## Internal Loop
1. Initial Search → 3 query variations
2. Source Evaluation → score each source (0-100)
3. Ranking → sort by score
4. Gap Analysis → identify missing evidence
5. Targeted Search → search specifically for gaps
6. Final Ranking → select best sources
7. Synthesis → produce rigorous answer

## Quality Criteria
- Prefer primary sources (papers, official docs)
- Prefer peer-reviewed content
- Evaluate credibility, relevance, evidence quality, recency
- Never invent facts or citations

## Output
- Summary with evidence-based claims
- List of sources with scores
- Confidence level
- Gaps identified
